# Блокнот — заметки с синхронизацией телефона и ПК

Одно приложение, два способа открыть:

- **Телефон** — APK-файл, который GitHub собирает сам.
- **ПК** — сайт по адресу `https://ТВОЙ_НИК.github.io/bloknot/`.

Заметки хранятся в твоём бесплатном Firebase. Входишь одной и той же почтой и паролем на обоих устройствах — заметки общие. Без интернета приложение тоже работает и досылает изменения, когда связь появится.

Всё делается один раз, примерно 15 минут.

---

## Часть 1. Firebase (хранилище заметок)

**Шаг 1. Создай проект.**
Зайди на https://console.firebase.google.com под своим Google-аккаунтом → «Создать проект» (Create a project) → назови `bloknot` → Google Analytics можно выключить → «Создать».

**Шаг 2. Получи данные для приложения.**
На главной странице проекта нажми значок **`</>`** (Web / «Добавить приложение» → Web) → название `Блокнот` → «Зарегистрировать». Галочку Firebase Hosting **не ставь**.
Firebase покажет код с `const firebaseConfig = { apiKey: "...", ... }`. Скопируй всё, что в фигурных скобках `{ ... }` вместе со скобками, и сохрани где-нибудь — понадобится в шаге 7.

**Шаг 3. Включи вход по почте.**
Слева «Build» (Создание) → **Authentication** → «Начать» (Get started) → вкладка «Sign-in method» → **Email/Password** → включи первый переключатель → «Сохранить».

**Шаг 4. Создай базу заметок.**
Слева «Build» → **Firestore Database** → «Создать базу данных» → регион выбери любой из Европы (например `eur3`) → режим **production** → «Создать».
Когда база откроется, перейди на вкладку **«Правила» (Rules)**, сотри всё, что там написано, вставь содержимое файла `firestore.rules` из этого проекта и нажми **«Опубликовать» (Publish)**.

Эти правила значат: каждый человек видит только свои заметки.

---

## Часть 2. GitHub (сборка APK и сайт)

**Шаг 5. Создай репозиторий.**
Зайди на https://github.com → справа сверху «+» → **New repository** → имя `bloknot` → **Public** → «Create repository».

**Шаг 6. Загрузи файлы.**
На странице нового репозитория нажми ссылку **«uploading an existing file»**.
Открой распакованную папку проекта, выдели **всё внутри** (Ctrl+A) и перетащи в окно браузера. Важно, чтобы загрузилась и папка `.github` — на Mac она скрыта, покажи её сочетанием Cmd+Shift+. (точка).
Внизу нажми **«Commit changes»**.

Проверь: в репозитории должны быть папки `.github`, `android`, `tools`, `web`. Если `.github` нет — смотри раздел «Если что-то пошло не так».

**Шаг 7. Впиши данные Firebase.**
В репозитории открой `web/config.js` → значок карандаша (Edit) → замени объект внутри `window.FIREBASE_CONFIG = { ... };` на тот, что скопировал в шаге 2 → «Commit changes».

**Шаг 8. Включи сайт для ПК.**
Репозиторий → **Settings** → слева **Pages** → в «Source» выбери **GitHub Actions**.
Потом вкладка **Actions** → слева «Сайт для ПК» → справа **«Run workflow»** → «Run workflow».

**Шаг 9. Подожди сборку.**
Во вкладке **Actions** появятся две задачи: «Сборка APK» и «Сайт для ПК». Через 3–5 минут у обеих должна быть зелёная галочка.

---

## Часть 3. Пользуемся

**Телефон.** Открой на телефоне `https://github.com/ТВОЙ_НИК/bloknot/releases/latest` → скачай **Bloknot.apk** → открой файл. Android попросит разрешить установку из этого источника — разреши, и установка продолжится.

**ПК.** Открой `https://ТВОЙ_НИК.github.io/bloknot/` и добавь в закладки.

**Первый вход.** В любом из них впиши почту и придумай пароль → «Создать аккаунт». На втором устройстве с той же почтой и паролем нажми «Войти». Готово.

**Обновления.** Каждый раз, когда ты (или я) меняешь файлы в репозитории, GitHub сам собирает новую версию. Новый APK ставится поверх старого, заметки никуда не деваются.

---

## Если что-то пошло не так

- **В приложении написано «Почти готово».** Не заполнен `web/config.js` (шаг 7), или в нём осталось `ВСТАВЬ_СЮДА`.
- **«Не включён вход по почте».** Повтори шаг 3.
- **«Firebase не пускает к заметкам».** Не опубликованы правила — повтори конец шага 4.
- **Во вкладке Actions пусто.** Не загрузилась папка `.github`. Нажми «Add file» → «Create new file», впиши имя `.github/workflows/android.yml`, вставь текст этого файла из папки проекта и сохрани. Так же для `.github/workflows/pages.yml`.
- **Красный крестик у «Сайт для ПК».** Обычно значит, что шаг 8 ещё не сделан. Сделай его и запусти задачу заново.
- **Красный крестик у «Сборка APK».** Открой задачу, скопируй текст ошибки и пришли мне.

### Что внутри

- `web/` — само приложение (HTML). Его же показывает и сайт, и APK.
- `android/` — оболочка Android, которая открывает `web/` внутри приложения.
- `tools/firebase-entry.js` — из него при сборке получается `web/firebase.js`.
- `.github/workflows/` — инструкции для GitHub: собрать APK и выложить сайт.
- `firestore.rules` — правила доступа к базе.

Ключ подписи APK (`android/app/release.jks`) лежит в открытом репозитории — для личного блокнота это нормально. Просто ставь APK только со своей страницы Releases.
